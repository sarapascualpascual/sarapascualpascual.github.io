# Repository guidelines

## Authorship and attribution

Do not add automated development tool names, branding, signatures or author/co-author credits to source files, comments, documentation, README files, commit messages, commit trailers, pull requests, generated artifacts, public pages or project metadata. Use neutral, descriptive commit messages and preserve truthful Git identity metadata. Do not falsify authorship or rewrite history to conceal provenance. Preserve all legally required third-party copyright notices, licenses and attributions.

## Publication and privacy

Publish only explicitly approved professional information. Never commit credentials, private notes, unpublished personal information or confidential employer material. Follow the publication gates in docs/portfolio-spec.md.
